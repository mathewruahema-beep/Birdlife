# The learning ladder

Ranked by what will make you better at this job, not by what is fashionable.
Reps beat courses. Courses beat certifications. Certifications matter for the
Board's confidence and your next role, and one of them matters a great deal.
Every link checked 3 September 2026.

## Rung 1: this week, free, three hours

| Resource | Why this one | Time |
|---|---|---|
| [Anthropic Academy](https://anthropic.skilljar.com/) | The official free courses with completion certificates. Start with the prompting and Claude Code tracks. Sign up with any email. | 2 hrs |
| [Anthropic prompt engineering interactive tutorial](https://github.com/anthropics/prompt-eng-interactive-tutorial) | Hands-on, exercise by exercise. The fastest way to stop writing weak prompts. | 1 hr |
| [Claude Code best practices](https://code.claude.com/docs/en/best-practices) | The operating manual for the tool you use daily. | 30 min |

## Rung 4: twelve months, the one that matters for a security manager

| Resource | Why this one | Watch out |
|---|---|---|
| [ISACA Advanced in AI Security Management (AAISM)](https://www.isaca.org/credentialing/aaism) | The only AI-centric security management credential. It is exactly your role: run AI in the organisation while identifying, assessing and mitigating its risks. [Exam content outline](https://www.isaca.org/credentialing/aaism/aaism-exam-content-outline). | Requires CISM or CISSP first. If you hold neither, CISM is the twelve-month goal and AAISM follows. That is the honest sequence. |

## Keep reading, thirty minutes a week

- [One Useful Thing](https://www.oneusefulthing.org/) for how people actually work with AI.
- [Anthropic engineering blog](https://www.anthropic.com/engineering) for how the tool is changing.
- [OWASP Top 10 for LLM Applications](https://genai.owasp.org/resource/owasp-top-10-for-llm-applications-2025/) once a quarter, because the list changes.

## The push

Rung 1 this week, no excuses, it is three hours. Book the AI-900 exam date now
so rung 3 has a deadline. Decide by the end of the month whether CISM is the
twelve-month goal. If it is, tell the CEO, because it needs budget and study

carry weight.
