# One Thing Today, the daily focus tool

`focus/index.html` is a single-file, personal daily companion built for Mathew. It
is not part of the ICT assistant and touches no BirdLife system. It stores
everything in the browser's local storage and sends nothing anywhere.

## What it does, in the order of a day

1. **Now panel.** The one task, the smallest physical next step, and a timer
   (10, 25, 45 minute focus; 5 or 15 minute break). The timer survives reloads.
   "I'm stuck" gives one concrete unstick move.
2. **State check.** Hungry, Tired, Wound up, Been alone. It returns a plain
   verdict on whether this is a decision window. "Ground me" opens box breathing
   and a 5-4-3-2-1 senses list.
3. **Check-in, Te Whare Tapa Whā.** Tinana, hinengaro, whānau, wairua on a
   1 to 5 scale, sleep last night, the basics, and the three tasks for the day.
4. **Brain dump.** Park intrusive thoughts. Items carry across days until done.
5. **Wins.** Timestamped. Ticking a task done logs a win automatically.
6. **Evening close.** What I enjoyed, one thing I did well (evidence), the one
   thing for tomorrow, mood at close. Tomorrow's one thing becomes tomorrow's
   first task automatically.
7. **Last 14 days and Evidence.** Focus minutes, closing mood, sleep average,
   and every win and "did well" entry from the fortnight.

## Using it on a phone

Open the published artifact in Chrome or Samsung Internet, then use the browser
menu to add it to the Home screen. Data lives in that browser only. Use
Export under "Settings, alerts, backup" before switching devices, and Import on
the new one.
