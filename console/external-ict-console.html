The engagement rules

Separation. Nothing from BirdLife crosses into external work: no connector, no credential, no document, no licence, no template with BirdLife content in it. This page holds notes only and reaches no external system.
Authorisation before access. No admin action in a client tenant without written scope naming the systems, the changes allowed, and who signed. A verbal OK is not authorisation.
Own identity, own device. Named admin account per client, MFA on, never a shared login. Client data stays in the client tenant; it does not land on a personal drive.
Propose, then change. State the exact change and get the go-ahead. Log every change where the client can see it. Never bulk-delete, never disable a test to make a check pass.
Declare the conflict. Any client that competes with, supplies to, or funds BirdLife is declared to BirdLife before work starts. Outside-work policy applies regardless of the hours.

Essential Eight, the one-line read

StrategyThe question that finds the gap
Application controlCan a standard user run an installer from Downloads? If yes, Maturity Level 1 is not met.
Patch applicationsAre browsers and Office patched within 48 hours of a critical fix, and who checks?
Configure Office macrosAre macros from the internet blocked by policy, not by user choice?
User application hardeningIs Internet Explorer 11 removed, Java and ads blocked in the browser, PowerShell logging on?
Restrict admin privilegesHow many Global Administrators, and do any of them read email on that account?
Patch operating systemsAre there unsupported Windows or server versions still on the network?
Multi-factor authenticationIs MFA enforced for every user including external and service accounts, and is legacy auth blocked?
Regular backupsMicrosoft 365 has no native backup. What restores a deleted SharePoint site after 93 days, and when was that tested?

Grade each against Maturity Level 1 first. Most small organisations fail MFA, admin privileges and backups before anything else.

Closing an engagement takes three things

  • Access removed. Your admin account in their tenant disabled or deleted, and the client shown that it is.
  • Handover written. What changed, what is still open, what the next person needs, sent to the client contact.
  • Register closed. Status set to Closed here with the date, so the Desk stops chasing it.
