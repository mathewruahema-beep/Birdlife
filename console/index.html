When someone joins

  • Start in Employment Hero — use "Add Employee", never the CSV quick-add. The BLA### worker code is required; use their personal email for the invite.
  • Their address will be firstname.lastname@birdlife.org.au; they get an M365 Business Premium licence.
  • Create the account, add the licence, put them in the right groups and lists, set their manager, and tell IT + their manager it's done.
  • If they've worked here before, reactivate the old account — never make a duplicate.

Closing a case — the trap

A case won't close with just the status — you must set two things together: Status = "Closed" and a close reason (Case_Closed_Reason__c). The valid reasons:

Closed - Resolved · Closed - Resolved First Call · Closed - Email Sent · Closed - Email Edited & Sent · Closed - Phone Call · Closed - No Action Required · Closed - Internal Follow up · Closed - Duplicate · Closed - Spam · Closed - Abandoned · Closed - Autoreply · Closed - Returned Letter

What the statuses mean

Salesforce saysPlain English
NewJust arrived — nobody has replied yet
In ProgressBeing worked on
Waiting Response-ExternalWaiting on them (the requester)
Response ReceivedThey replied — the ball is back with us
Pending / On Hold-InternalParked for now

Owner = 'Zeus' means nobody owns it yet — it's the intake queue, not a person. And always count cases with the Ask Zeus record type filter; without it you're counting every team's cases (~200× too many).

Useful queries

SELECT CaseNumber, Subject, Status, Type, Owner.Name, CreatedDate
FROM Case
WHERE RecordType.DeveloperName = 'Zeus' AND IsClosed = false
ORDER BY Owner.Name, CreatedDate ASC
SELECT Id, Name, IsActive, Username FROM User
WHERE Name = 'Keith Tsui' AND IsActive = true

Run the second one before reassigning a case — team members have more than one active user record, so never guess the ID.
