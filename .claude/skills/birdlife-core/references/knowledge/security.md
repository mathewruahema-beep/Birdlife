# Security Knowledge Digest — BirdLife Australia ICT
Compiled: 2026-08-02. Source: all 21 .md files under `kb/text/Security` (source material dated 19–30 June 2026, i.e. ~5 weeks old at compilation).

## 1. Purpose & scope of the security programme
- A 12-month Azure/M365 security uplift programme ("Azure Security Programme — Technical Implementation Guide v2.0") aligned to the **ASD Essential Eight, target Maturity Level 2**, structured in 4 phases: Phase 1 Critical (MFA enforcement, Global Admin reduction, Defender for Cloud, 12 Azure Monitor alerts, SharePoint sharing enforcement); Phase 2 Foundational (Intune enrolment, app-registration restriction, auth-methods migration, Azure Policy CIS baseline, Identity Secure Score to 70%+); Phase 3 Hardening (password protection, app consent, named locations, ADAL→MSAL); Phase 4 Governance (Defender for M365, diagnostic logging, 129-app permission review, PIM, quarterly reviews, backup verification, IR runbook, annual pen test A$15–30k).
- Designed for NFP licensing constraints: maximise existing M365; flags Entra ID P2 (~A$2,500/yr for ~15 admins) and Defender for Servers as paid upgrades.
- Parallel workstreams: Microsoft Defender XDR / Essential Eight 12-week remediation plan; Intune configuration uplift; MFA remediation campaign for @birdlife.org.au staff; hardening of no-MFA shared/service accounts (IT-SEC-001); WordPress security review + 2FA rollout; Salesforce org config and user security reviews; M365 enterprise-application user access review.
- Change rule: all CA changes deploy Report-only first (7–14 days) with documented rollback; break-glass accounts (breakglass01/02@birdlife.org.au) excluded from all CA policies.
